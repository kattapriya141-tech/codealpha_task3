# Project Management Tool

## 📌 Project Overview
The Project Management Tool is a web application that helps users manage projects and tasks efficiently. It provides an easy-to-use interface for organizing work, tracking progress, and managing project details.

## 🚀 Features
- User Login Page
- Project Dashboard
- Create and Manage Projects
- Task Management
- Simple and Responsive User Interface
- Easy Navigation

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## 📁 Project Structure

Project-Management-Tool/
│── index.html
│── login.html
│── style.css
│── script.js
│── server.js
│── package.json
│── package-lock.json

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install dependencies:

```bash
npm install
```

5. Start the server:

```bash
node server.js
```

6. Open your browser and visit:

```
http://localhost:3000
```
